# RESQAI — GitHub Pages Demo

A responsive static front-end prototype for RESQAI, an AI-assisted disaster response and emergency coordination project.

## Publish on GitHub Pages
1. Sign in to GitHub as `sathwika418`.
2. Create a **public** repository named `resqai`.
3. Upload `index.html` to the repository's root (top-level) folder and commit.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Choose branch **main** and folder **/(root)**, then save.
7. Wait a few minutes. Your expected URL is:
   https://sathwika418.github.io/resqai/

## Features in this demo
- Responsive RESQAI landing page and dashboard
- Device geolocation to show latitude and longitude
- Copy coordinates for sharing
- Emergency helpline 112 and nearby-hospital map search
- SOS demo flow with a clear notice that no rescue team is contacted

## Important limitations
This is a front-end demo only. It does not have a backend, database, live disaster feeds, automatic rescue dispatch, or real SOS notifications. Do not rely on this demo as an emergency service. For an emergency in India, call 112.
